# Renterio - Rental & Interior Design Website

Rinterio is a modern rental and interior design website showcasing professional services, portfolio works, and client engagement features.  
It is built with **HTML5, CSS3**, ensuring a fully responsive, user-friendly, and visually appealing design.

## Features

- **Modern UI/UX** – Clean and minimal design with smooth interactions.
- **Responsive Layout** – Fully optimized for mobile, tablet, and desktop devices.

- **Hero Banner** – Eye-catching landing section with call-to-action.
- **About Us Section** – Highlights services with engaging visuals.
- **Work Process** – Step-by-step design workflow cards.
- **Services Section** – Showcases construction, interior design, and renovation services.
- **Portfolio Showcase** – Grid-based portfolio with detailed project previews.
- **Statistics Highlights** – Client reviews, departments, happy clients, and staff members.
- **Contact Form** – Users can easily connect for project discussions.
- **Footer Section** – Quick navigation and call-to-action button.
